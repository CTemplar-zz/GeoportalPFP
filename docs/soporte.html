GEOPORTAL PFP · BOLIVIA

Ayuda y soporte

Consulta mapas, áreas protegidas e indicadores territoriales de Bolivia desde tu iPhone. No necesitas crear una cuenta.

Activar y ordenar capas

Abre Capas, elige un módulo y despliega un grupo. En Activas puedes cambiar la transparencia y usar las flechas para ordenar las capas: las primeras se dibujan encima.

Datos INE por cuenca

Abre Capas → Datos INE → Marco espacial y activa Cuencas Hidrográficas (Nivel 3). Abre Datos → Por cuenca y selecciona una cuenca. El panel incluye indicadores, fichas PDF disponibles, el Excel consolidado y un filtro de superposición con áreas protegidas.

Guardar y compartir

Las descargas utilizan la hoja de compartir de iOS. Elige Guardar en Archivos o una aplicación compatible. La disponibilidad de fichas depende de la información incorporada.

Conexión

Los mapas base, capas grandes, WMS y ciertos reportes requieren internet. La app incluye algunos recursos locales; no descarga toda la cartografía remota. Puedes elegir Solo capas como mapa base para consultar geometrías locales.

Ubicación opcional

Solo se solicita al pulsar el control de ubicación. Puedes denegar el permiso y seguir usando la aplicación.
